# woman 使用接口定义

本文供后续开发者实现，定义命令入口和用户可见行为，不指定内部实现方案。
当前代码仅有 CLI 参数、分发和占位函数，以下查找、选择、翻译、缓存与展示行为均为待实现要求。

## 命令形式

```sh
mytool woman <手册名称> [--section <分类编号>] [--refresh | --original]
```

无需管道输入。

| 参数 | 含义 |
|---|---|
| `<手册名称>` | 必填，例如 `printf`、`ls` |
| `--section <分类编号>` | 可选，指定目标手册分类，例如 `1`、`3`；未指定时查找本机所有匹配手册 |
| `--refresh` | 跳过中文译文缓存，重新翻译选定的手册 |
| `--original` | 查看选定手册的英文原文，不翻译，不发起模型请求 |
| `-h` / `--help` | 显示用法 |

`--refresh` 与 `--original` 互斥，不能同时使用。
分类编号用于区分同名手册，不是文档内部的章节号；普通用户无需预先知道分类编号。

## 查找与选择

执行示例：

```sh
mytool woman printf
```

程序先查本机有哪些匹配的手册：

- 没有匹配：提示未找到该手册，结束，不触发翻译。
- 只有一个匹配：直接进入该手册的阅读流程，不要求用户选择。
- 有多个匹配：显示名称、分类编号、分类说明和简短简介，让用户选择。

以下仅为输出示例，实际条目以本机已安装手册为准：

```text
找到多篇手册，请选择：

[1] printf(1)  终端命令：格式化输出
[2] printf(3)  C 库函数：格式化输出

请输入选项：
```

方括号内是本次列表的选择序号；圆括号内是手册分类编号。
输入 `2` 表示选择列表第二项，不是选择第 2 类手册。

- 简介应来自对应本机手册；无法获取时显示“暂无简介”。不应为生成选择列表调用模型。
- 同名、同分类但来源不同的条目，应显示来源路径，便于区分。
- 输入无效编号时提示有效范围，并允许重新输入。
- 用户取消选择或输入结束时结束流程，不触发翻译。
- 指定 `--section` 后，先限制匹配范围，再按零个、一个、多个匹配执行上述规则。

## 选定后的阅读行为

| 情况 | 行为 |
|---|---|
| 默认模式，已有有效中文译文 | 打开对应译文，不重新翻译 |
| 默认模式，没有有效中文译文 | 翻译选定手册，保存成功后打开译文 |
| 使用 `--refresh` | 重新翻译选定手册；成功后更新缓存，失败时保留旧译文 |
| 使用 `--original` | 打开选定的英文原文 |

先选定手册，再查缓存或翻译，不为全部候选项预先翻译。
手册内容保存为文件；SQLite 用于记录缓存索引和元数据，不要求存储原文、译文正文。
缓存需区分同名但分类、来源或原文版本不同的手册，不能只凭名称命中。

## Python 调用入口

保留当前 CLI 调用约定：

```python
def woman(
    manual_name: str,
    *,
    section: str | None = None,
    refresh: bool = False,
    original: bool = False,
) -> None:
    ...
```

该函数负责组织完整阅读流程，正常结束不返回待打印的译文字符串。
业务失败以 `RuntimeError` 交给现有 CLI 输出错误。
内部查找、选择、翻译、缓存和展示模块的拆分由实现者决定。
