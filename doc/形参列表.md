# argparse 接口与形参列表

本文整理配置 CLI 时涉及的主要公开接口，签名按本机 **Python 3.15.1** 的标准库核对。范围包括解析器、子命令、参数、分组、解析结果和自定义处理入口，不展开私有实现方法。

阅读约定：

- 代码中的 `def ...: ...` 是函数签名展示，省略了实现。
- `self` 是实例方法接收当前对象的形参，调用 `parser.parse_args()` 时不需要手动传入。
- `*args` 收集额外的位置实参；`**kwargs` 收集额外的关键字实参。
- 单独的 `*` 表示后面的形参只能按关键字传入。
- `**kwargs` 不代表任意字段都有效，最终仍由具体接口或 Action 校验。

## 1. 创建解析器：ArgumentParser

```python
import argparse

class ArgumentParser:
    def __init__(
        self,
        prog=None,
        usage=None,
        description=None,
        epilog=None,
        parents=[],
        formatter_class=argparse.HelpFormatter,
        prefix_chars="-",
        fromfile_prefix_chars=None,
        argument_default=None,
        conflict_handler="error",
        add_help=True,
        allow_abbrev=True,
        exit_on_error=True,
        *,
        suggest_on_error=True,
        color=True,
    ): ...
```

这里展示构造函数的形参；实际使用时创建 `argparse.ArgumentParser(...)`，不需要自己声明这个类。`parents=[]` 按标准库签名保留，不作为自行编写函数时使用可变默认值的建议。

| 形参 | 含义 |
| --- | --- |
| `prog` | 帮助中显示的程序名，默认根据启动方式生成，例如 `mytool`。 |
| `usage` | 自定义用法说明；默认根据已定义的参数生成。 |
| `description` | 帮助中位于参数列表之前的说明。 |
| `epilog` | 帮助中位于参数列表之后的说明，例如使用示例。 |
| `parents` | 引入这些 parser 已定义的参数和默认值。 |
| `formatter_class` | 帮助排版类。 |
| `prefix_chars` | 选项前缀字符集合，默认 `-`。 |
| `fromfile_prefix_chars` | 参数文件前缀字符集合；例如设为 `@` 后，可通过 `@args.txt` 展开文件中的参数。 |
| `argument_default` | 参数没有单独指定时采用的默认值策略；设为 `argparse.SUPPRESS` 可避免为未提供的参数创建结果属性。 |
| `conflict_handler` | 同名选项冲突的处理方式，`error` 报错，`resolve` 处理覆盖；旧 Action 的其他选项名可能保留。 |
| `add_help` | 是否自动注册帮助选项，通常是 `-h/--help`。 |
| `allow_abbrev` | 是否接受没有歧义的长选项缩写。 |
| `exit_on_error` | 是否将解析错误按退出流程处理；设为 `False` 可捕获部分 `ArgumentError`，不保证所有路径都不退出。 |
| `suggest_on_error` | 是否对拼错的字符串取值、子命令名提供建议。 |
| `color` | 是否允许彩色帮助；实际显示还取决于终端和环境。 |

`parents` 常用于复用公共选项。公共 parser 通常设置 `add_help=False`，避免重复的帮助选项；先完整定义公共参数，再创建使用它的 parser。后来向公共 parser 新增参数，不会自动补到已有的使用方。

### formatter_class 的常用取值

| 值 | 含义 |
| --- | --- |
| `argparse.HelpFormatter` | 默认排版，自动换行。 |
| `argparse.RawDescriptionHelpFormatter` | 保留 `description`、`epilog` 的原有排版。 |
| `argparse.RawTextHelpFormatter` | 也保留参数帮助的空白排版，但连续空行可能合并。 |
| `argparse.ArgumentDefaultsHelpFormatter` | 在参数帮助中补充默认值。 |
| `argparse.MetavarTypeHelpFormatter` | 使用参数类型名作为取值占位符。 |

## 2. 创建子命令入口：add_subparsers

```python
def add_subparsers(self, **kwargs): ...
```

调用形式：`commands = parser.add_subparsers(...)`。返回子命令管理对象，随后通过 `commands.add_parser(...)` 创建具体的子 parser。

| kwargs 字段 | 含义与默认行为 |
| --- | --- |
| `dest` | 把选中的子命令名存入哪个结果属性；默认不保存，常设为 `command`。 |
| `required` | 是否必须选择子命令，默认 `False`。 |
| `parser_class` | 创建子 parser 使用的类，默认是当前 parser 的类型。 |
| `action` | 负责子命令选择的 Action；默认使用内置实现，通常不修改。 |
| `title` | 帮助中子命令分组的标题。 |
| `description` | 子命令分组的说明。 |
| `help` | 子命令选择这一项的帮助文字。 |
| `metavar` | 帮助中子命令位置的占位文字，默认列出可选命令。 |
| `prog` | 为子 parser 生成程序名时使用的前缀，默认根据主 parser 的用法生成。 |

一个 parser 只能添加一个子命令选择入口；在该入口下可以注册多个命令。子 parser 自身还能继续调用 `add_subparsers()`，形成多层命令。

## 3. 创建具体子命令：add_parser

```python
def add_parser(self, name, *, deprecated=False, **kwargs): ...
```

这个方法属于子命令管理对象，调用方式是 `commands.add_parser(...)`，不是 `parser.add_parser(...)`。

| 形参或 kwargs 字段 | 含义 |
| --- | --- |
| `name` | 子命令正式名称，必填，例如 `trans`。 |
| `deprecated` | 是否在使用该命令时提示弃用，默认 `False`。 |
| `aliases` | 同一个命令的其他名字，例如 `["tr", "translate"]`，默认没有别名。 |
| `help` | 上一级帮助中显示的命令简介。 |
| 其余构造字段 | 传给子 parser 构造函数，例如第 1 节中的 `description`、`parents`、`formatter_class`、`allow_abbrev`。 |

`prog` 默认组合成类似 `mytool trans` 的名称。若指定了自定义 `parser_class`，其构造函数决定还能接受哪些字段。

需要区分：

- `help` 是命令列表中的简介，`description` 是该命令自身帮助中的说明。
- `parser_class` 配置在 `add_subparsers()`，标准 `ArgumentParser` 的构造函数不接受这个字段。
- 别名指向同一个子 parser；若设置 `dest="command"`，结果保存用户实际输入的名字，例如 `tr`，不会自动归一为 `trans`。

## 4. 定义参数：add_argument

```python
def add_argument(self, *args, **kwargs): ...
```

位置实参用于指定参数名或选项字符串：

```python
parser.add_argument("filename")
parser.add_argument("-o", "--output")
```

| kwargs 字段 | 含义 |
| --- | --- |
| `action` | 参数出现时执行的动作，默认保存值。 |
| `nargs` | 一次消耗几个输入值。 |
| `const` | 某些动作或可省略取值的选项使用的常量。 |
| `default` | 参数未出现、且结果对象中没有该属性时采用的值。 |
| `type` | 将输入字符串转换成目标值的可调用对象，例如 `int`、`float`、`Path` 或自定义函数；也可使用已注册的类型名称。 |
| `choices` | 允许的取值集合，在类型转换后检查。 |
| `required` | 是否要求选项出现，默认 `False`；位置参数的数量要求由 `nargs` 等规则决定。 |
| `help` | 参数帮助文字；设为 `argparse.SUPPRESS` 可以隐藏该条帮助。 |
| `metavar` | 帮助中的取值占位符，不决定结果属性名。 |
| `dest` | 结果属性名，例如 `request_timeout` 对应 `args.request_timeout`。 |
| `deprecated` | 是否在使用该参数时提示弃用，默认 `False`。 |
| `version` | `action="version"` 专用，指定输出的版本字符串。 |

返回值是描述该参数规则的 `Action` 对象。不同 Action 接受的字段不完全相同，自定义 Action 还可以定义额外字段。

### action 的常用取值

| 值 | 行为 |
| --- | --- |
| `"store"` | 保存输入值，默认动作。 |
| `"store_const"` | 出现时保存 `const`。 |
| `"store_true"` | 出现时保存 `True`，默认值通常为 `False`。 |
| `"store_false"` | 出现时保存 `False`，默认值通常为 `True`。 |
| `"append"` | 每次出现，把本次取值追加到列表。 |
| `"append_const"` | 每次出现，把 `const` 追加到列表。 |
| `"extend"` | 把本次取得的一组值展开后加入列表，常配合 `nargs="+"`。 |
| `"count"` | 统计出现次数；需要从零开始时可以设置 `default=0`。 |
| `"help"` | 显示帮助并退出。 |
| `"version"` | 显示版本并退出。 |
| `argparse.BooleanOptionalAction` | 自动提供 `--cache` 和 `--no-cache` 这样的正反选项。 |
| 自定义 Action 类或已注册名称 | 自定义取值处理行为。 |

### nargs 的常用取值

| 值 | 含义 |
| --- | --- |
| 不指定 | 普通保存动作通常接收一个值，结果是单个值。 |
| 正整数 `N` | 接收恰好 N 个值；普通保存动作得到列表，`N=1` 时也是列表。 |
| `"?"` | 接收零个或一个值。对选项而言：选项未出现使用 `default`，出现但未跟值时使用 `const`。 |
| `"*"` | 接收零个或多个值，通常得到列表。 |
| `"+"` | 接收一个或多个值，通常得到列表。 |
| `argparse.REMAINDER` | 将剩余输入作为这个参数的值。 |

## 5. 参数分组

### 普通分组：add_argument_group

```python
def add_argument_group(self, *args, **kwargs): ...
```

| 参数 | 含义 |
| --- | --- |
| `title` | 分组标题，可按位置或关键字传入。 |
| `description` | 分组说明，可按位置或关键字传入。 |
| `argument_default` | 组内参数的默认值策略，按关键字传入。 |
| `conflict_handler` | 组内选项冲突处理策略，按关键字传入。 |

返回分组对象，通过 `group.add_argument(...)` 添加参数。普通组主要改变帮助展示，结果仍写入同一个 Namespace。

### 互斥分组：add_mutually_exclusive_group

```python
def add_mutually_exclusive_group(self, **kwargs): ...
```

| kwargs 字段 | 含义 |
| --- | --- |
| `required` | 默认 `False`，表示最多选一个；设为 `True` 表示必须恰好选一个。 |

互斥组自身不接受 `title`、`description`。可以先建普通组，再在其中创建互斥组。互斥约束不能直接表达任意参数依赖关系。

## 6. 默认值：set_defaults、get_default

```python
def set_defaults(self, **kwargs): ...

def get_default(self, dest): ...
```

| 接口 | 形参含义与结果 |
| --- | --- |
| `set_defaults(**kwargs)` | 关键字名称作为结果属性名，值作为默认值；名称由应用自定义，没有固定字段清单。 |
| `get_default(dest)` | `dest` 是结果属性名，返回对应的默认值。 |

例如 `trans_parser.set_defaults(func=translate)` 保存函数对象，不会执行函数。程序需要主动调用 `args.func(...)`。

## 7. 解析命令行

```python
def parse_args(self, args=None, namespace=None): ...

def parse_known_args(self, args=None, namespace=None): ...

def parse_intermixed_args(self, args=None, namespace=None): ...

def parse_known_intermixed_args(self, args=None, namespace=None): ...
```

| 共同形参 | 含义 |
| --- | --- |
| `args` | 待解析的字符串列表，例如 `["trans", "--refresh"]`；默认读取 `sys.argv[1:]`。 |
| `namespace` | 将结果写入哪个已有对象；默认创建 `argparse.Namespace`。 |

| 方法 | 行为与返回值 |
| --- | --- |
| `parse_args` | 要求完整匹配，返回解析结果对象。 |
| `parse_known_args` | 允许未识别参数，返回 `(结果对象, 剩余参数列表)`；仍会检查已识别参数的规则。 |
| `parse_intermixed_args` | 在支持的语法中处理选项与位置参数交错，返回结果对象。 |
| `parse_known_intermixed_args` | 交错解析并保留未识别参数，返回二元组。 |

交错解析不支持子命令等部分结构。`parse_known_args()` 仍可能使用长选项缩写规则，并非无条件将未知前缀原样保留。`argparse` 不自动读取管道正文，正文需要通过 `sys.stdin` 等途径读取。

## 8. 帮助输出与错误处理

```python
def format_usage(self, formatter=None): ...

def format_help(self, formatter=None): ...

def print_usage(self, file=None): ...

def print_help(self, file=None): ...

def error(self, message): ...

def exit(self, status=0, message=None): ...
```

| 方法 / 形参 | 含义 |
| --- | --- |
| `format_usage` | 返回用法字符串，不直接输出。 |
| `format_help` | 返回完整帮助字符串，不直接输出。 |
| `formatter` | 本版本允许传入 formatter 实例；默认根据 parser 的 `formatter_class` 创建。较早 Python 版本的这两个方法没有该形参。 |
| `print_usage`、`print_help` 的 `file` | 输出目标，默认标准输出；可传入 `sys.stderr`。 |
| `error` 的 `message` | 错误说明；原生实现输出用法和错误信息，并以状态码 2 退出。 |
| `exit` 的 `status` | 退出状态码，默认 0。 |
| `exit` 的 `message` | 可选消息，输出到标准错误后退出。 |

项目里的 `MytoolParser` 继承 `ArgumentParser` 并重写 `error()`，因此错误时可以输出完整帮助。没有定义自己的 `__init__()` 时，会继承父类的构造方法。

## 9. 扩展入口

```python
def convert_arg_line_to_args(self, arg_line): ...

def register(self, registry_name, value, object): ...
```

| 方法 / 形参 | 含义 |
| --- | --- |
| `convert_arg_line_to_args` 的 `arg_line` | 参数文件中的一行文字；方法返回该行对应的参数序列，默认一行作为一个参数。 |
| `register` 的 `registry_name` | 注册类别，例如 `"type"` 或 `"action"`。 |
| `register` 的 `value` | 后续引用的注册名称。 |
| `register` 的 `object` | 注册的转换函数或 Action 类等对象。 |

### 自定义 Action 的基础定义

```python
class Action:
    def __init__(
        self,
        option_strings,
        dest,
        nargs=None,
        const=None,
        default=None,
        type=None,
        choices=None,
        required=False,
        help=None,
        metavar=None,
        deprecated=False,
    ): ...

    def __call__(self, parser, namespace, values, option_string=None): ...
```

构造参数中，`option_strings` 是这个 Action 的选项名集合，`dest` 是结果属性名；其余字段与 `add_argument()` 中对应字段的含义一致。自定义动作通常继承 `argparse.Action` 并实现 `__call__()`：

| __call__ 形参 | 含义 |
| --- | --- |
| `parser` | 当前解析器。 |
| `namespace` | 当前解析结果对象。 |
| `values` | 经过数量匹配、类型转换等步骤后交给动作的值。 |
| `option_string` | 触发动作的选项名，例如 `--timeout`；位置参数通常为 `None`。 |

### Namespace 的构造定义

```python
class Namespace:
    def __init__(self, **kwargs): ...
```

关键字会成为结果对象的属性。例如 `argparse.Namespace(timeout=30)` 可以通过 `args.timeout` 读取。属性名由参数的 `dest`、子命令的 `dest` 和 `set_defaults()` 等配置决定。

## 10. 一个串联主要接口的例子

```python
import argparse

common = argparse.ArgumentParser(add_help=False)
common.add_argument("--timeout", type=int, default=30)

parser = argparse.ArgumentParser(prog="mytool")
commands = parser.add_subparsers(dest="command", required=True)

trans_parser = commands.add_parser(
    "trans",
    aliases=["tr"],
    parents=[common],
    help="翻译文本",
    description="把输入文本翻译成中文。",
    epilog="示例：mytool trans --refresh",
    formatter_class=argparse.RawDescriptionHelpFormatter,
)
trans_parser.add_argument("--refresh", action="store_true")

args = parser.parse_args(["tr", "--timeout", "10", "--refresh"])
print(args)
# Namespace(command='tr', timeout=10, refresh=True)
```

这个例子只演示参数解析，不执行翻译。所有配置放置的位置分别是：主 parser 构造、子命令入口、具体子 parser 构造、具体参数定义。

## 11. 版本差异与参考

| 版本 | 与本文相关的变化 |
| --- | --- |
| Python 3.9 | 增加 `exit_on_error` 和 `BooleanOptionalAction`。 |
| Python 3.13 | 参数和子命令支持 `deprecated`。 |
| Python 3.14 | 增加 `suggest_on_error`、`color`；其中 `suggest_on_error` 默认 `False`。 |
| Python 3.15 | `suggest_on_error` 默认改为 `True`。 |

签名以本机 Python 3.15.1 的 `inspect.signature()` 和标准库源码为核对依据；使用其他解释器时，应核对该版本的接口。

- [Python 3.15 argparse 官方参考](https://docs.python.org/zh-cn/3.15/library/argparse.html)
- [Python 3.14 argparse 官方参考](https://docs.python.org/3.14/library/argparse.html)
